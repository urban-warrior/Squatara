# Setting Up a Development Environment

1. **Install esptool**

    * May be available in system package manager
    * If not or for latest version(recommended), install with pipx
    * pipx may require a separate install

2. **Install PlatformIO**

    * Use system package manager to search for PlatformIO, often found as platformio-core
    * For convenience, there may be associated UDEV rules for PlatformIO devices

3. **Terminal Emulator**

    * This author has found the PlatformIO device monitor to be barely
   functional, if not useless -- YMMV
    * The recommended program is tio
    * The documentation-recommended CoolTerm did not appear to work
   correctly on Linux
